# Roles & Levels

## Getting verified
Read the rules, then react with ✅ on the rules message in #roles to get the **Verified** role. Only verified members can chat in the main channels.

## Level roles
You earn XP by chatting (spamming does not count).
- Level 10: **Regular**
- Level 30: **Veteran**
- Level 50: **Legend**, which also unlocks a custom name colour.

## Becoming a moderator
Moderator applications open a few times a year and are announced in #announcements. Requirements: active on the server for at least 3 months, Level 20 or higher, and no warnings in the last 6 months.
